常见问题 FAQ

如何开始使用 TokenHub？

+

开始使用 TokenHub 非常简单，只需以下几个步骤：

  1. 注册账户：访问我们的官网，点击"注册"按钮创建账户
  2. 充值余额：进入充值页面，选择适合的金额进行充值
  3. 获取 API Key：在控制面板中生成您的专属 API Key
  4. 开始调用：使用 API Key 调用我们的接口，享受优惠的 AI 服务

详细教程请查看 API 文档中心

支持哪些支付方式？充值后多久到账？

+

我们支持多种支付方式：

  • ✅ 支付宝 - 即时到账
  • ✅ 微信支付 - 即时到账
  • ✅ Payspi 聚合支付 - 支持多种国际支付方式
  • ✅ 人工转账 - 适合大额充值，需人工确认

在线支付通常是即时到账的，充值完成后余额会立即更新。如果遇到延迟，请检查支付状态或联系客服。

API Key 如何获取和管理？

+

获取 API Key 的步骤：

  1. 登录您的 TokenHub 账户
  2. 进入"控制面板" > "API 密钥管理"
  3. 点击"创建新密钥"按钮
  4. 为密钥命名（如：生产环境、测试环境）
  5. 复制并安全保存您的 API Key（只显示一次）

安全提示：

  • 不要将 API Key 提交到代码仓库
  • 建议使用环境变量存储
  • 定期轮换密钥以提高安全性
  • 如发现泄露，立即删除并重新生成

如何申请发票？

+

发票申请流程：

  1. 登录账户，进入"财务管理" > "发票申请"
  2. 选择需要开票的充值记录
  3. 填写发票抬头和税号信息
  4. 选择发票类型（电子发票/纸质发票）
  5. 提交申请，我们将在 3-5 个工作日内处理

注意事项：

  • 单张发票最低金额：¥100
  • 电子发票发送至注册邮箱
  • 纸质发票包邮寄送到填写地址
  • 如有疑问请联系客服

遇到 API 调用错误怎么办？

+

常见错误及解决方案：

  • 401 Unauthorized - API Key 无效或过期，请检查密钥是否正确
  • 429 Too Many Requests - 请求频率超限，请降低调用频率或升级套餐
  • 500 Internal Server Error - 服务器内部错误，请稍后重试或联系客服
  • 402 Payment Required - 余额不足，请及时充值

完整错误码列表请参考 API 文档 - 错误码 章节。

可以退款吗？退款政策是什么？

+

我们的退款政策：

  • ✅ 未使用余额：可随时申请全额退款
  • ✅ 7 天内：扣除已使用部分，剩余金额可退
  • ❌ 超过 7 天：原则上不支持退款，特殊情况请联系客服
  • ❌ 赠送金额：活动赠送的余额不可退款

退款申请路径：控制面板 > 财务管理 > 申请退款
