欢迎使用 TokenHub API

TokenHub 提供兼容 OpenAI 格式的 API 接口，让您能够轻松接入全球主流 AI 大模型。 只需修改 API Base URL 和 API Key，即可在几分钟内完成集成。

快速入门

按照以下步骤，快速开始使用 TokenHub API：

  1. 注册账号：访问 tokenhub.com/register 注册账号
  2. 获取 API Key：登录后在控制台创建 API Key
  3. 配置 SDK：设置 API Base URL 和 API Key
  4. 发起请求：调用 API 测试功能
✅ 新用户福利

注册即送 ¥10 体验金，无需充值即可体验所有模型！

Python 示例 
import openai

# 配置 TokenHub API
openai.api_base = "https://api.tokenhub.com/v1"
openai.api_key = "sk-your-api-key"

# 调用 GPT-4
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello!"]
)

print(response.choices[0].message.content)

认证方式

TokenHub API 使用 Bearer Token 进行认证。您需要将 API Key 添加到 HTTP 请求的 Authorization 头中。

Authorization Header 
Authorization: Bearer sk-your-api-key
⚠️ 安全提示

请妥善保管您的 API Key，不要将其泄露给他人或提交到代码仓库。建议通过环境变量管理 API Key。

对话补全 API

使用聊天补全 API 与 AI 模型进行对话。支持多轮对话、系统消息设定等功能。

参数 类型 必填 说明
model string 是 模型名称，如 gpt-4, claude-3
messages array 是 消息列表，包含 role 和 content
temperature number 否 随机性，范围 0-2，默认 1
max_tokens integer 否 最大生成 token 数
cURL 示例 
curl https://api.tokenhub.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{
    "model": "gpt-4",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "temperature": 0.7
  }'

常见问题

Q: 如何获取 API Key？

A: 登录控制台后，进入「API 密钥」页面，点击「创建新密钥」即可生成。请妥善保存，密钥只会显示一次。

Q: 支持的模型有哪些？

A: 目前支持 OpenAI (GPT-3.5/4)、Anthropic (Claude 3)、Google (Gemini)、DeepSeek、MiniMax 等主流模型。完整列表请查看模型页面。

Q: 如何计费？

A: 按实际使用的 Token 数量计费，不同模型价格不同。您可以在控制台实时查看用量明细和消费记录。

Q: 充值后多久到账？

A: 支付成功后立即到账，支持支付宝、微信支付等多种支付方式。

错误码说明

错误码 说明 解决方案
400 请求参数错误 检查请求参数格式和内容
401 认证失败 检查 API Key 是否正确
429 请求频率超限 降低请求频率或升级套餐
500 服务器内部错误 联系技术支持
